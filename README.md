# Vértice Porcelanato — landing page

## Troque antes de publicar
1. **WhatsApp/telefone**: `script.js` → `WHATSAPP_NUMBER` e `PHONE_DISPLAY` (+ `telephone` no JSON-LD do `index.html`).
2. **E-mail**: `contato@verticeporcelanato.com.br` no rodapé do `index.html`.
3. **Instagram**: `instagram.com/verticeporcelanato` no rodapé.
4. **Endpoint do formulário**: `script.js` → `FORM_ENDPOINT` (Formspree ou Apps Script do Google Sheets). Vazio = envia só pelo WhatsApp.
5. **Domínio**: troque `https://vertice-porcelanato.vercel.app/` em `index.html` (canonical, OG, JSON-LD), `robots.txt` e `sitemap.xml`.

Também: CNPJ (placeholder no rodapé) e os 3 depoimentos ilustrativos (troque por avaliações reais e remova o aviso).

## Checklist de publicação
- [ ] Itens acima trocados
